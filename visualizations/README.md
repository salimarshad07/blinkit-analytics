# Blinkit Analytics Visualizations

This folder contains all PNG charts generated from the Python EDA analysis.

## Charts

1. **chart1_segment_revenue.png** — Bar chart showing revenue distribution across customer segments (Regular, New, Premium, Inactive)
2. **chart2_delivery_performance.png** — Pie chart displaying delivery performance metrics (On Time 69.84%, Slightly Delayed 20.92%, Significantly Delayed 9.24%)
3. **chart3_category_margin.png** — Horizontal bar chart showing average margin percentage by product category
4. **chart4_order_distribution.png** — Histogram of order values with mean (₹2,227) and median (₹2,137) indicators

## Usage

These visualizations are exported from `blinkit_eda.py` and used in the Tableau dashboard.
